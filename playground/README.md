# Dirban Extension Test Playground

This is a dedicated sandbox workspace for manually running, testing, and verifying the **Dirban VS Code Extension**.

## Getting Started

1. Press **F5** in VS Code (with the root `dirban` workspace open) or run **"Run Dirban Extension (Playground)"** from the Run & Debug pane.
2. The Extension Development Host will open directly inside this `playground` folder.
3. Check the Activity Bar for the **Dirban** lightning icon to view the **Sidebar TreeView**.
4. Run `Cmd+Shift+P` (or `Ctrl+Shift+P`) and choose **"Dirban: Open Kanban Board"** to open the full-width Webview board tab.
5. Test interactions:
   - **Drag-and-drop** cards across columns.
   - Click a card to open the **Detail Drawer** and check off acceptance criteria.
   - Click **Open File ↗** or double click cards to open markdown files.
   - Click **+ New Task** to create tasks.
